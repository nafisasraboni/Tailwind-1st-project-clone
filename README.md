# 🥗 Nature's Platter - E-Commerce Landing Page

A responsive, modern e-commerce landing page built for an online grocery and pet essentials shop. This project focuses on clean UI design, responsive layouts, and Tailwind CSS utility classes.

🔗 **Live Demo:** https://nature.sraboni.dev

---

## 📌 Project Overview

Nature's Platter is a frontend e-commerce interface designed to provide an intuitive shopping experience. It features high-quality promotional banners, structured product grids, service highlights, and an interactive newsletter layout.

---

## ✨ Key Features

- 📱 **Fully Responsive Layout:** Seamlessly optimized across mobile, tablet, and desktop screens using Tailwind breakpoint utilities.
- 🎯 **Hero & Promotional Banners:** Visually appealing hero banner showcasing special offers and discounts.
- 🛒 **Popular Products Grid:** Structured section displaying featured grocery items using CSS Grid and Flexbox.
- 🚚 **Services Section:** Highlights delivery and customer service offerings with custom icons.
- 📬 **Interactive Newsletter:** Card layout overlapping the footer section implemented using Tailwind relative positioning and z-index.
- ⚡ **High Performance Deployment:** Fast asset delivery hosted on Cloudflare Pages.

---

## 🛠️ Main Technologies Used

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** Tailwind CSS (v4 Utility-First Framework)
- **Iconography:** Font Awesome (v6.5.1 Vector Icons)
- **Hosting & Infrastructure:** Cloudflare Pages

---

## 📦 Dependencies & Resources

- **Tailwind CSS v4:** Included via CDN / setup file (`assets/tailwind.init.css`)
- **Font Awesome v6.5.1:** Vector icon library for UI elements

## ⚙️ How to Run Locally

1. **Clone the repository:**
   git clone https://github.com/nafisasraboni/Tailwind-1st-project-clone.git

2. **Navigate to the project directory:**
   cd Tailwind-1st-project-clone

3. **Open in Browser:**
   Open the `assets/index.html` file directly in your browser or run it using VS Code Live Server
