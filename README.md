# Nature's Platter 🥗

A responsive, modern e-commerce landing page built for an online grocery and pet essentials shop. This project focuses on clean UI design, responsive layouts, and Tailwind CSS utility classes.

🌐 **Live Demo:** [nature.sraboni.dev](https://nature.sraboni.dev)

---

## 🚀 Features

* **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
* **Hero & Banner Sections:** Clean promotion sections with custom styling.
* **Services & Popular Products Grid:** Organized product showcase using Tailwind Grid and Flexbox.
* **Interactive Newsletter Box:** Elevated card layout overlapping the footer section using `relative` and `z-index`.
* **Fast Performance:** Hosted on Cloudflare Pages for ultra-fast load times.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **Tailwind CSS (v4):** Modern utility-first CSS framework.
* **Font Awesome (v6.5.1):** Scalable vector icons.
